# MSEide+MSEgui FAQ

Sources of [MSEide+MSEgui FAQ](https://msegui.net/tutoriels/faq-msegui/index.html).

## Contributor's guide

The MSEgui FAQ is written in Markdown. The HTML files are generated by [Pandoc](https://github.com/jgm/pandoc).

To create a new entry, copy an existing Markdown file (for example [onkeyup.md](faq-msegui-en/onkeyup.md)) and give it the name of your choice, let us say *configuration.md*.

Then create the HTML page as follows:

```
make configuration
```

Or create all pages:

```
make all
```
